# Project Management System

This is a simple web-based Project Management System built using **Flask** and **MySQL**.

It allows users to manage projects and tasks in an easy dashboard-style interface.

---

## 💡 Features
- Add, edit, and delete projects
- Add, edit, and delete tasks under each project
- Dashboard showing total projects, total tasks, and completed tasks

---

## 🧠 Technologies Used
- Python (Flask Framework)
- MySQL Database
- HTML for basic frontend

---
